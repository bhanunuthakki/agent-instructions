# Exploration

Use this reference for the initial open-ended work and each later analytical deep dive.

## Define one leg

Frame a leg around one decision-relevant question. State the proposed scope, necessary inputs, intended artifact, and stopping point. Ask only questions whose answers would materially change that work.

For a first pass, inventory source files, periods, grains, identifiers, supplied definitions, missing fields, and required outputs. Keep source observations separate from inferred business meaning.

## Build only enough analysis

Start with direct reconciliations and simple cuts. Add a calculation when it can distinguish competing explanations, size a material issue, or support a decision. Do not produce a full analytical suite because the case is broad.

Maintain a lightweight question ledger:

- question or hypothesis
- source and population
- calculation or artifact
- finding
- limitation
- whether it merits another leg

External research is appropriate when current benchmarks or industry practice will change the interpretation or recommendation. Prefer primary sources and strong practitioner evidence. Label it as outside context.

## End each leg

Return a compact handoff: question tested, main finding, confidence and limitation, artifact created, recommended next leg, and any owner decision needed. Do not imply the case is complete or advance to pruning without a clear request.
